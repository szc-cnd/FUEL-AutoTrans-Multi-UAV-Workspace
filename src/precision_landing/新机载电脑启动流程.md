# 新机载电脑一键启动流程

适用设备：`/home/asus/db_ws`，下视 Generic USB Camera，ROS Noetic，PX4 + MAVROS。

## 首次准备

```bash
source /opt/ros/noetic/setup.bash
cd /home/asus/db_ws
catkin_make
source devel/setup.bash
chmod +x /home/asus/scripts/start_onboard_landing.sh
chmod +x /home/asus/db_ws/src/precision_landing/scripts/start_landing_test.sh
```

确认标定文件存在：

```bash
ls -l /home/asus/.ros/camera_info/down_camera.yaml
```

## 实飞启动

先启动雷达定位和 MAVROS，然后执行唯一启动命令：

```bash
source /opt/ros/noetic/setup.bash
source /home/asus/db_ws/devel/setup.bash
/home/asus/scripts/start_onboard_landing.sh
```

脚本会打开一个 Terminator 窗口并分成三个画面：

1. 左上：下视相机，使用 by-id 路径、640×480、MJPG、60 FPS，并加载 `down_camera.yaml`。
2. 右上：`rqt_image_view /landing/debug_image`，查看 ArUco 边框、ID、状态和误差。
3. 下方：起飞、悬停、触发降落、对准、缓降和近地 AUTO.LAND 切换，同时显示主任务日志。

## 重复启动规则

再次执行命令时：

- 已有 `/usb_cam`：跳过相机启动；
- 已有 `/precision_landing_node` 或 `/landing_test`：跳过降落任务启动；
- 已有 `/landing/debug_image` 的 `rqt_image_view`：跳过重复画面；
- 已有 Precision Landing Terminator 窗口：不再新建窗口。

这样不会因为重复执行命令造成同名 ROS 节点互相关闭。

## 重新启动

确认无人机已经上锁、停桨后，关闭本次三分屏窗口，再重新执行启动命令。也可以执行：

```bash
/home/asus/scripts/start_onboard_landing.sh stop
/home/asus/scripts/start_onboard_landing.sh
```

不要在无人机仍处于飞行或 OFFBOARD 控制时使用 `stop`。

## 日志位置

- 起飞降落日志：`/home/asus/db_ws/landing_logs/landing_*.log`
- 下视相机日志：`/tmp/precision_landing_down_camera.log`
- 检测画面日志：`/tmp/precision_landing_rqt_image_view.log`
- Terminator 启动日志：`/tmp/precision_landing_terminator.log`
