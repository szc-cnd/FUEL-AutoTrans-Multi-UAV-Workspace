# 精简实飞启动流程

前提：雷达定位和 MAVROS 已经启动并正常工作。

## 复制代码后必须执行一次

每次从 Windows 重新复制 `precision_landing` 文件夹到 Ubuntu 后，执行：

```bash
sed -i 's/\r$//' ~/db_ws/src/precision_landing/scripts/start_landing_test.sh
chmod +x ~/db_ws/src/precision_landing/scripts/start_landing_test.sh
cd ~/db_ws
catkin_make
source ~/db_ws/devel/setup.bash
```

其中 `chmod +x` 用于恢复启动脚本的可执行权限，否则 `rosrun` 会提示脚本不是可执行文件。

## 终端 1：启动下视相机

```bash
source /opt/ros/noetic/setup.bash
source ~/db_ws/devel/setup.bash
roslaunch precision_landing down_camera.launch
```

## 终端 2：查看 ArUco 检测画面

```bash
source /opt/ros/noetic/setup.bash
source ~/db_ws/devel/setup.bash
rqt_image_view
```

在 `rqt_image_view` 中选择：

```text
/landing/debug_image
```

该话题会在终端 3 启动起飞降落程序后出现。

## 终端 3：启动自动起飞、精准降落和日志

```bash
source /opt/ros/noetic/setup.bash
source ~/db_ws/devel/setup.bash
rosrun precision_landing start_landing_test.sh
```

自动流程：

```text
倒计时 5 秒
→ 解锁并进入 OFFBOARD
→ 发送 2.05 米高度目标（±0.05 米，下限正好为 2.00 米）
→ 实际相对高度达到至少 2.00 米
→ 确认高度约 0.10 秒后立即发送降落触发
→ 保持当前位置悬停，持续搜索并对准 ArUco
→ 1.5 米以上视觉对准下降
→ 1.5 米处记录融合定位 X/Y
→ 固定 X/Y，Z 目标以 0.10 m/s 缓慢降低
→ 近地 cutoff 触发后请求 PX4 切换 AUTO.LAND
→ 由 PX4 完成最后下降和停桨
```

日志自动保存到：

```text
~/db_ws/landing_logs/
```

查看最新日志：

```bash
ls -lt ~/db_ws/landing_logs | head
```

不要另外启动：

```text
roslaunch precision_landing precision_landing.launch
```

`start_landing_test.sh` 启动的 `landing_test.launch` 已经包含检测和降落节点。
