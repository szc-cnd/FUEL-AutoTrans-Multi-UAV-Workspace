# LDOP 动态避障接口说明

本文档面向使用 LDOP 动态障碍物检测结果进行动态避障和轨迹规划的开发人员。

## 1. 系统职责

LDOP 负责：

```text
点云输入 → 动态点提取 → 目标聚类 → 跨帧跟踪 → 输出动态目标状态
```

动态避障/规划模块负责：

```text
读取动态目标状态 → 结合无人机自身运动和安全距离进行碰撞预测 → 生成避障轨迹
```

LDOP 中的轨迹预测模块可以提供通用的未来轨迹参考，但最终的碰撞判断和避障决策应由动态避障模块完成，因为规划模块才知道无人机的规划时域、飞行约束、通道边界和安全距离。

## 2. 推荐使用的接口

### 2.1 主接口：当前动态目标状态

```text
话题：/ldop/dynamic_objects
类型：ldop/DynamicObjectArray
发布者：/ldop_node
频率：约 10 Hz
```

消息定义：[`msg/DynamicObject.msg`](../msg/DynamicObject.msg)

每个目标包含：

| 字段 | 含义 |
|---|---|
| `id` | 跨帧跟踪 ID。不要使用数组下标作为目标 ID。 |
| `size` | 当前目标包围盒尺寸，单位 m。 |
| `model_state` | 当前运动模型的状态向量。 |
| `model_covariance` | 状态协方差矩阵，按 row-major 展开。 |
| `object_class` | 目标类别。当前系统关闭分类，通常为 `CLASS_UNKNOWN=0`。 |
| `motion_model_type` | `model_state` 的布局类型。 |

当前小球通常使用 `CV3D` 模型：

```text
motion_model_type = 2
model_state = [x, y, z, vx, vy, vz]
```

其中：

- `[x, y, z]`：目标中心位置，单位 m；
- `[vx, vy, vz]`：目标速度，单位 m/s；
- `size`：目标包围盒尺寸，可用于障碍物膨胀；
- `header.stamp`：该目标状态对应的时间戳。

规划模块至少应使用 `id`、目标中心、速度和尺寸。对于本次地面小球场景，可以使用水平位置和水平速度进行预测，并使用目标高度和安全余量处理垂向碰撞。

### 2.2 可选接口：LDOP 通用未来轨迹预测

```text
话题：/ldop/dynamic_object_predictions
类型：ldop/DynamicObjectPredictionArray
发布者：/ldop_node
频率：约 10 Hz
```

消息定义：[`msg/DynamicObjectPredictionArray.msg`](../msg/DynamicObjectPredictionArray.msg)

当前配置：

```text
prediction_horizon: 1.0          # 未来 1 秒
prediction_max_branches: 3       # 每个目标最多 3 条分支
prediction_min_branch_probability: 0.05
```

每个预测目标包含：

```text
id
size
object_class
motion_model_type
matched_in_current_frame
branches[]
```

每条预测分支包含：

```text
behavior_type
behavior_value
probability
points[]
```

每个预测点包含：

```text
time_from_start
model_state
model_covariance
influence_weight
```

预测点的 `time_from_start` 是相对于 `header.stamp` 的未来时间。例如：

```text
time_from_start = 0.3 s
model_state = 该目标在 header.stamp + 0.3 s 的预测状态
```

当前 `CV3D` 预测点的 `model_state` 仍然是：

```text
[x, y, z, vx, vy, vz]
```

`probability` 是该分支的相对概率，同一个目标的所有保留分支概率之和为 1。三条分支代表三种可能的运动趋势，不代表检测到了三个障碍物。

### 2.3 调试接口：动态点云

```text
话题：/ldop/dynamic_cloud
类型：sensor_msgs/PointCloud2
```

这是当前帧的动态点云，适合 RViz 调试和观察点云质量，不建议作为动态避障的主要目标接口，因为它没有稳定的目标 ID、目标尺寸和目标级速度。

## 3. 坐标系和时间

当前动态目标消息的 `header.frame_id` 通常为：

```text
camera_init
```

动态避障模块应确认自己的规划坐标系。如果规划使用其他坐标系，需要使用 TF 将目标位置、速度和预测点统一转换后再进行碰撞判断。

注意：位置和预测点不能只看数值，必须同时使用消息的 `header.frame_id` 和 `header.stamp`。

检查命令：

```bash
rostopic type /ldop/dynamic_objects
rostopic type /ldop/dynamic_object_predictions
rostopic echo -n 1 /ldop/dynamic_objects/header
rostopic echo -n 1 /ldop/dynamic_object_predictions/header
```

## 4. 避障模块推荐接法

### 基础接法：使用当前状态自行预测

推荐动态避障模块首先订阅：

```text
/ldop/dynamic_objects
```

对每个目标读取：

```text
当前位置 = model_state[0:3]
当前速度 = model_state[3:6]
障碍物尺寸 = size
```

然后在自己的规划周期内做匀速或带限加速度预测。这样避障模块可以自行控制：

- 预测时长；
- 障碍物膨胀半径；
- 碰撞判定阈值；
- 无人机自身运动影响；
- 通道边界和安全距离。

### 增强接法：使用 LDOP 多分支预测

如果规划器已经支持多分支轨迹和概率，可以额外订阅：

```text
/ldop/dynamic_object_predictions
```

规划器应：

1. 按 `id` 找到对应目标；
2. 遍历该目标的 `branches[]`；
3. 使用 `probability` 对每条分支进行风险加权；
4. 对每条分支的 `points[]` 做时序碰撞检查；
5. 结合目标 `size` 和规划器自身安全余量进行障碍物膨胀。

不要把多条分支拼成一条折线，也不要只取数组中的第一条分支而忽略概率。

## 5. 本次地面小球场景的注意事项

当前检测分类已关闭，因此 `object_class` 不应作为是否避障的必要条件。动态避障应依据目标是否存在、位置、速度、尺寸和跟踪 ID 工作。

对于地面小球：

- 主要使用 `x/y` 位置和 `vx/vy` 速度；
- `z/vz` 方向的微小变化可能来自点云和定位噪声；
- LDOP 预测中出现的垂向分支不一定代表小球真的起飞；
- 若规划器只做水平通道避障，可以将预测点投影到水平面，并按小球尺寸增加安全半径；
- 若目标暂时漏检，不要永久保留上一帧目标；应根据消息时间戳和跟踪状态设置超时。

## 6. 运行和检查

启动检测：

```bash
source /home/oem/ldop_ws/ldop_env.sh
bash /home/oem/scripts/ros_start_ldop_detection.sh
```

关闭全部 ROS 进程：

```bash
bash /home/oem/scripts/ros_stop_all.sh
```

检查接口：

```bash
rostopic info /ldop/dynamic_objects
rostopic hz /ldop/dynamic_objects
rostopic info /ldop/dynamic_object_predictions
rostopic hz /ldop/dynamic_object_predictions
```

检查结果时应确认：

- 发布者是 `/ldop_node`；
- 频率约 10 Hz；
- 目标 `id` 不应使用数组顺序代替；
- 没有动态目标时应按当前帧处理空消息，不能无限使用旧目标；
- 预测分支中的 `time_from_start` 应按消息时间戳解释。

## 7. 接口选择结论

当前比赛开发建议：

```text
主接口：/ldop/dynamic_objects
可选增强：/ldop/dynamic_object_predictions
调试观察：/ldop/dynamic_cloud
```

主接口提供可靠的当前目标状态，动态避障模块据此完成最终预测和避障决策；预测接口作为通用未来轨迹参考使用。
