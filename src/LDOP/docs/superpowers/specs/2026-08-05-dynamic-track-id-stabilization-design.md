# 动态目标 ID 稳定跟踪优化设计

## 目标

在点云遮挡、局部碎片和小球摆动时保持同一动态障碍物的轨迹 ID；同时不把固定杆的点云抖动发布为动态目标。默认 RViz 只显示已经确认有运动证据的轨迹框。

## 依据

现场监听到无人机在飞行过程中，主目标轨迹先后出现 ID5、ID12、ID13，局部碎片还短暂生成 ID10、ID15、ID17、ID19。固定杆附近的 ID7 位置约为 `(3.7,-2.7,1.0)`，速度接近零。现有尺寸关联门槛、重复合并距离和单帧运动证据共同导致了这些现象。

## 设计

1. 在 `TrackState` 中增加一次性确认的动态状态。只有滤波后的速度达到运动确认阈值，轨迹才对外发布；确认后即使目标短暂停止，仍保持原 ID。
2. 对已确认动态轨迹放宽近距离局部碎片的尺寸限制，优先回关联到旧轨迹，不创建新 ID。重复轨迹合并距离调整到覆盖现场观测的 0.5～0.7 m，同时只合并明显的碎片、未确认轨迹或漏检轨迹，避免合并两个相互独立且尺寸相近的目标。
3. 复用现有漏检保活窗口，不增加长期残留；固定杆只要没有运动确认就不进入 `/ldop/dynamic_objects` 和预测输入。
4. 增加稳定轨迹框 Marker，并在默认 RViz 中关闭原始候选框显示；原始 `/ldop/dynamic_object_markers` 话题继续保留供调试。

## 验证标准

- 编译成功，参数能从 `ldop.yaml` 加载。
- 现场复测时，小球在短时遮挡或产生局部碎片后继续使用原 ID。
- 固定杆的静止抖动不再出现在 `/ldop/dynamic_objects`；默认 RViz 不显示其原始红色候选框。
- 不安装新的依赖，不改变动态避障接口 `/ldop/dynamic_objects`。
